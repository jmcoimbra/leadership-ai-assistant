# Contributing

Welcome. This is a template repo for engineering managers' AI-native brains. Contributions that help future users are welcome.

## Good Contributions

- **Clearer template language.** Better placeholder names, less ambiguous instructions.
- **New generalizable knowledge files.** Patterns that apply across many engineering orgs.
- **New skills that work for any EM.** Self-contained, no company-specific context.
- **Hook improvements.** More configurable, fewer hardcoded assumptions.
- **Documentation fixes.** Typos, broken cross-references, missing context.

## Not Good Contributions

- Company-specific patterns, dashboards, or doctrines.
- Real person data, even anonymized.
- Tool integrations that require a specific vendor (unless behind a clear opt-in).
- Adding back the personal log structures that were stripped to make the template public.

## How to Submit

1. Fork the repo.
2. Make your changes on a feature branch.
3. Open a PR with a clear description: what does this add, who benefits, why is it generic.
4. The maintainer will review for: template fidelity (no personal data leaks), generic applicability, and consistency with the existing voice profile.

## Code of Conduct

Keep it professional. Disagree on the substance. Reject anything that reads as anonymizing someone's personal data — those should not have been written into the template in the first place.
